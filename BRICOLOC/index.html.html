Comment ça marche

Trois étapes, sans prise de tête

1

Réservez en ligne

Choisissez vos dates, payez en ligne. La caution est une simple empreinte bancaire, jamais débitée si tout va bien.

2

Récupérez avec un code

Vous donnez votre code de remise au propriétaire : il vaut état des lieux et déclenche la location.

3

Rendez et notez

Au retour, le code de retour clôt la location et libère la caution. Chacun note l'autre.
